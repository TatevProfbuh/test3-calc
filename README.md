# Калькулятор стоимости бухгалтерского обслуживания — ТАТЕВ

Одна страница (`index.html`): расчёт ежемесячной стоимости сопровождения ИП/ООО по прайсу 2026
и выгрузка коммерческого предложения в PDF.

- Работает в браузере, без установки; после загрузки страницы интернет не нужен.
- Логотип встроен в файл — других файлов не требуется.
- Кнопка «Скачать КП в PDF» сразу сохраняет файл «КП — клиент — дата.pdf».

## Публикация на GitHub Pages

1. Загрузите `index.html`, `README.md` и `.nojekyll` в репозиторий.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту страница будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.
